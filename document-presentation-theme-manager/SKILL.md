# Document & Presentation Theme Manager

Approved package, version 1.0. These are independent styles, not official school brand standards.

In the Global Skills Registry, activate this skill on explicit user request. Once activated, select the theme automatically using the routing below. Do not activate it for unrelated work.

## Select the theme

Use the current user's explicit theme name or number first. Otherwise route by purpose and audience, not filename or file extension:

| Purpose | Theme | Definition |
|---|---|---|
| Student assessment, worksheet, revision sheet, study guide, or printable learning handout | 1 · Academic Clarity | [Theme 1](themes/academic-clarity.md) |
| Formal Science Department report, departmental review, leadership report, or official departmental summary | 2 · Institutional Professional | [Theme 2](themes/institutional-professional.md) |
| Engaging classroom teaching PPT/PPTX, scientific explanation, inquiry, or lesson presentation | 3 · Scientific Discovery | [Theme 3](themes/scientific-discovery.md) |

A leadership report delivered as slides still routes to Theme 2. A student study guide delivered as slides routes to Theme 1. For multiple deliverables, route each independently and state the selection briefly. If purpose is ambiguous, use the dominant audience and state the assumption; ask only when competing purposes would materially alter the output. For an unspecified general document use Theme 1 provisionally; for an unspecified classroom deck use Theme 3.

Each theme is complete and independent: never import another theme's palette, fonts, or layout by inheritance. Shared preservation and accessibility rules apply to all three.

## Overrides and precedence

Resolve constraints in this order: current user instructions; mandatory school requirements and protected source elements; explicit theme choice; theme defaults; optional templates. Apply local overrides only to the requested scope (for example, body size, paper size, or one diagram). Do not silently make them permanent or blend themes. Record material deviations.

Honor user overrides while checking readability and integrity. If a requested choice causes a failure, identify it and offer a concrete accessible alternative; do not silently claim it passed. If mandatory school requirements conflict with the user's request, explain the conflict and resolve it before altering protected elements.

Theme 1 defaults to dual digital/grayscale use even when printing is not mentioned. A request for grayscale in any other theme activates the print adaptation in its definition. An explicit Theme 3 choice for an assessment is allowed, but must still preserve assessment integrity and requested print suitability.

## Apply without changing meaning

Inspect the source and identify protected regions before formatting. Preserve school letterhead, logos, crest, official wording, header/footer placement, dimensions, proportions, and reserved clear space. Do not recolor, redraw, crop, replace, or cover them. Keep existing paper size and slide ratio unless instructed otherwise. If letterhead clearance is unspecified, retain its source footprint and position the body below it.

Preserve wording, question and subquestion order, marks, answer spaces, rubric criteria, totals, citations, links, dates, tables, chart data, units, equations, subscripts/superscripts, image labels, speaker notes, and hidden slides. Preserve intentional section/page breaks and numbering. Do not reveal answer keys, hidden solutions, or examiner comments in student outputs. Do not rewrite, simplify, summarize, add scientific claims, or delete material as part of theming. If reflow cannot accommodate content, add space/pages/slides only where authorized and meaning remains intact; otherwise surface the conflict. Never shrink text below the theme minimum to force a fit.

Apply semantic heading/body/table/caption styles, document styles or slide master/layout roles where supported, rather than relying entirely on isolated manual formatting. Keep text and equations editable where possible. Read the chosen theme only, then [validation](references/validation.md). Read [template guidance](references/template-guidance.md) for supplied templates and [extension guidance](references/extensibility.md) when adding themes. Examples are in [routing and overrides](references/examples.md).

Use available document/presentation creation or editing tools for the actual format; this skill specifies styling, not a renderer. Preserve a source copy and create a separately named themed output unless the user requests in-place editing. Do not invent a school logo or official template when none is supplied.

## Accessibility and completion

Use at least 4.5:1 text contrast as the package default, including slide text; inspect meaningful diagram edges and controls against adjacent colors with a 3:1 target. Never communicate meaning by hue alone. Use labels, patterns, line styles, shapes, and visible text cues. Supply meaningful alt text for informative visuals, mark decoration appropriately, preserve logical reading order, real headings, table header identification, descriptive links, and presentation titles where supported. Do not fabricate alt text for an uninterpretable scientific figure; request its intended meaning or flag it for review.

Use the specified font fallback chain, selecting the first installed family with the needed glyphs. Do not download fonts without authorization. Check math and multilingual characters separately; retain appropriate specialist fonts for equations. Recheck wrapping and pagination after substitution.

Render and inspect the final output using the available format workflow; run its accessibility checker if available. Report the chosen theme, material overrides, fallback fonts, validation performed, and any limitations. A palette or successful export alone does not prove accessibility or grayscale print quality. Never claim checks that were not performed. References and the distinction between design targets and formal conformance are in [validation](references/validation.md).
