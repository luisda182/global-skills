# Examples and expected decisions

| Request | Expected behavior |
|---|---|
| “Format this Year 9 assessment for online use and photocopying.” | Theme 1, dual-use rules; preserve marks, order and answer space; inspect grayscale proof. |
| “Make this student revision guide look consistent.” | Theme 1 even without an explicit print request; retain content and support grayscale. |
| “Format our annual Science Department report for the principal.” | Theme 2; preserve school letterhead and report evidence. |
| “Create a formal PPT report of departmental results for leadership.” | Theme 2 by purpose, with its slide adaptation. |
| “Restyle these photosynthesis lesson slides.” | Theme 3; retain scientific labels, notes, order and learning content. |
| “Use Theme 1 for this classroom PPT study guide.” | Explicit Theme 1 wins; use its slide sizes and light background. |
| “Use Theme 2 but make body text 13 pt.” | Theme 2 plus body-size override for this output only; recheck reflow. |
| “Use Theme 3 for this assessment and make it grayscale.” | Honor the choice, apply print adaptation and assessment preservation; do not introduce answer cues. |
| “Apply Theme 1 but leave the school header exactly as supplied.” | Preserve header dimensions and colors; theme only the body; flag source header limitations without editing it. |
| “Make the report and a student worksheet from these supplied texts.” | Route report to Theme 2 and worksheet to Theme 1; do not mix their styles. |
| “Use red and green lines to distinguish results.” | Retain requested colors if readable, add direct labels and dash/marker distinctions; check grayscale if printing. |
| “Make this fit on one page.” | Preserve content and minimum type size; reduce optional spacing within safe limits, then explain if another page is needed. |

Example handoff after actual checks: “Applied Academic Clarity with Arial; kept letterhead, marks and answer spaces. Content comparison, contrast checks, rendered pages and grayscale proof passed. Physical printing and the target application's accessibility checker were not checked.” Adapt to evidence; never copy this as a claim without performing the checks.
