# Optional template guidance

Templates are optional accelerators. No school template, logo, licensed font or binary template is bundled or implied to exist.

When a user supplies a DOCX/DOTX/PPTX/POTX template, inspect its protected elements, styles, masters, theme colors, layout placeholders, page geometry and font dependencies before using it. Preserve the original and work on a copy. Prefer mapping theme roles onto existing body/heading/caption styles or slide layouts; do not replace the entire master if it contains school letterhead.

Separate protected school branding from theme-controlled content. Retain official headers, footers, logos, disclaimers, required type and spacing. Apply the chosen palette and fonts only to editable content regions. If a mandated template conflicts with the selected theme, keep the mandated elements and describe the resulting scoped adaptation. Ask only when the conflict requires a user decision, such as permission to alter a protected header.

Suggested future assets, only if requested:

- Theme 1: assessment and study-guide DOCX/DOTX styles with question, marks, answer space and figure roles, plus grayscale proof examples.
- Theme 2: report DOCX/DOTX with headings, captions, table styles and reserved letterhead area.
- Theme 3: PPTX/POTX master with title, explanation, comparison, diagram, discussion and references layouts.

Build each independently from its own definition. Use neutral empty content regions rather than invented school names or scientific facts. Validate each actual template in its target application and export path, including font fallback and grayscale where applicable. A template cannot guarantee accessibility of future inserted content.
