# Theme 2 · Institutional Professional

ID: `institutional-professional` · version 1.0 · independent definition.
Purpose: formal Science Department reports for leadership, colleagues and institutional records. This is a proposed report style, not an asserted official school identity.

## Visual tokens

| Role | Value |
|---|---|
| Page | White `#FFFFFF` |
| Body | Charcoal `#222222` |
| Headings, table header fill | Navy `#18334F` |
| Text on navy header | White `#FFFFFF` |
| Secondary text | Slate `#4B5563` |
| Optional table row fill | Light gray `#F3F4F6` |
| Essential rules and chart strokes | Gray `#626262` |

Use body, navy, or slate text on white/light gray only; white text only on navy. Use navy sparingly for hierarchy. Tables, captions, dates, section numbers and evidence should dominate over decoration. Do not introduce classroom stickers, gradients, mascots or invented institutional badges.

## Typography and layout

Headings: Aptos → Calibri → Arial → Liberation Sans. Body: Cambria → Georgia → Liberation Serif. Body 11.5–12 pt, never below 11 pt; title 22–26 pt; heading 1 16 pt, heading 2 13 pt; captions/footnotes 10 pt minimum. Use 1.15–1.3 body spacing and 6 pt after paragraphs. Apply real heading levels without skipping for appearance.

New reports: A4 portrait, 25 mm margins; retain source paper size and letterhead clearance. Use numbered headings where appropriate, page numbers, consistent table/figure captions, and a restrained running header only where it does not interfere with official letterhead. Use existing report sections; do not add an executive summary or fabricate recommendations during styling. Repeat table headers and avoid splitting single data rows where practical. Keep table values and chart scales unchanged.

For a formal report delivered as slides, use these same fonts and colors, titles 30–36 pt, body 22–28 pt, chart labels at least 18 pt. Preserve aspect ratio, otherwise use 16:9. Split dense content across slides only within the user's scope, preserving every item and note.

## Print adaptation

Use white pages, black text/headings and dark gray rules. Replace navy header fills with white, bold black header text, and clear borders when ink economy is requested. Supply direct chart labels, dash/marker distinctions and explicit status words. Render a grayscale proof when requested or when printed circulation is expected. Protected letterhead remains unchanged; disclose any source accessibility issue rather than recoloring it.
