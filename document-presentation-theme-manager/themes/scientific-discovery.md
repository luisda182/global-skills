# Theme 3 · Scientific Discovery

ID: `scientific-discovery` · version 1.0 · independent definition.
Purpose: engaging classroom PPT/PPTX presentations supporting scientific explanation, inquiry and discussion.

## Visual tokens

| Role | Value |
|---|---|
| Default canvas | White `#FFFFFF` |
| Body text | Ink `#172B3A` |
| Heading, links, primary diagram series | Deep teal `#005A66` |
| Secondary chart series and callout heading | Dark violet `#563A80` |
| Activity emphasis | Burnt orange `#9A3E00` |
| Optional callout surface | Pale blue `#EFF7F8` |
| Optional section divider canvas | Ink `#172B3A` |
| Text on dark divider | White `#FFFFFF` |

Use ink, teal, violet and orange text only on white or pale blue. Use white text on the dark divider; do not place dark accents on that divider. Distinguish chart series with labels and marker/dash differences as well as color. Accent colors indicate structure, never an unlabelled correctness or safety status.

## Typography and slide design

Titles: Aptos Display → Aptos → Calibri → Arial → Liberation Sans. Body: Aptos → Calibri → Arial → Liberation Sans. New decks: 16:9; preserve an existing deck's ratio. Titles 32–40 pt, body 24–28 pt, diagram labels at least 18 pt, small source credits at least 14 pt. Credits must remain legible; put full citations in notes or a references slide only if that does not remove required visible information. Never shrink task-critical text to credit size.

Maintain about 5% outer safe area on new slides, increasing for letterhead. Prefer a clear title and one teaching focus per slide, with generous space around diagrams. For newly authored content, use a mix of explanation, observation, prediction and discussion prompts when requested. For theming existing content, preserve slide order, all wording, learning objectives, questions, notes and hidden-slide state; do not invent activities or split/reorder slides without appropriate scope.

Use editable labelled diagrams, consistent arrows, visible axes and units, accurate image aspect ratios, and science imagery that clarifies a concept. Preserve meaningful microscopy/false-color keys and scale bars. Provide a light solid panel behind text over an image instead of relying on shadows. Avoid flashing, auto-advance dependencies, and animation required to understand a static export; inspect final animation/build states if retained.

## Handout or grayscale adaptation

Use white backgrounds including section dividers, black text, and dark gray strokes. Remove decorative fills when needed; retain clear borders and headings. Add labels/patterns/marker styles before conversion so the same teaching meaning survives. Keep photographs and scientific color legends scientifically faithful; if grayscale would destroy evidence, flag the need for color or an authorized equivalent. Render and inspect the intended handout arrangement—multiple slides per page can make otherwise readable labels too small. Enlarge or use fewer slides per page instead of silently accepting illegible text.
